# ♟️ Terminal Chessboard

A Python-based terminal chessboard project.

## About
This project aims to build a chessboard that runs directly in the terminal using Python.

## Features
- Display a chessboard in the terminal
- Represent chess pieces using symbols
- Interactive chess functionality (planned)

## Technologies Used
- Python

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/bhowmikkiran/terminal-chessboard.git
   ```
2. Navigate to the project directory.
3. Run:
   ```bash
   python "Chess basic.py"
   ```
